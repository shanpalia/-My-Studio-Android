# My Studio — Native Android

Photography editor starter built with Kotlin and Jetpack Compose.

Branding: **PaliaAPK HUB** · Developer: **shanpalia**

## Features in this starter
- Native Android app (not a WebView)
- White/blue home screen and branded splash screen
- System back navigation with an exit confirmation on Home
- Photo picker entry point and feature cards
- GitHub Actions debug APK build

## Build
Open this repository in Android Studio and run `:app:assembleDebug`, or download the APK from the GitHub Actions workflow artifact.

Note: advanced photo editing and online AI generation are not implemented by the UI scaffold yet. Local editing can be built without API fees; online AI may have provider limits/costs.
